## 資訊科技工作的性質
* 摩爾定律
    * 積體電路上，容量可在18-24個月成長一倍
    * 約6年10倍，約12年100倍，約18年1000倍
    * 1975-2015年非常符合，近10年約3-4倍
* 特殊性：
    * 跟時間賽跑：對比穩定的醫師、律師
    * 高技術需求：對比其它需要高學歷、證照
* 高報酬、高福利、股票激勵，每月5~10萬
* 需要不斷學習，技術容易過時，常有新機會
* 缺點：高彈性、責任制、需加班、需待命
* 危機：易因技術變革引發栽員潮，如AI浪潮

## 資訊科技工作需要的特質
* 強烈的好奇心：對新資訊容易了解和應用
* 終身學習的覺悟：累積自我學習的能力
* 極致的耐心和抗壓性：不找到解決方法不死心
* 嚴謹的羅輯思維：了解每個步驟間的因果關係
* 溝通與協作能力：要解決問題，就要和人溝通
* 對細節的執著：周延思考才能寫出沒問題軟體
* 積極的服務熱忱：科技始終來自於人性

## 資訊科技創業的收入吸引力
* 單次收入：開發一次，只收一次
    * 軟體開發費：累積成就感、建立客戶信任
    * 技術服務費：短時間可解決一個技術問題
* 多次收入：開發一次，可收多次
    * 軟體維護費：常期穩定收入、收入累積性
    * 軟體授權費：同性質產業軟體，可複製性
    * 資訊落差費：新技術不斷收取教學課程費
    * 平台使用費：低價使用費，積少成多特性
* 被動收入：穩定客戶，定期服務
    * 硬體差價費：設備淘汰快，被動收入特性

----

## 資訊科技創業的條件和優缺點
* 條件：
    * 技術敏銳力高：需具特殊性，不被取代
    * 市場敏銳力高：需創造有市場的產品
* 優點：
    * 創業門檻低：一台電腦即可啟動
    * 可複製性高：同一套軟體可多人使用
    * 製作工具多：用AI工具降低製作人力成本
* 缺點：
    * 員工成本高：人力成本不只高，流動亦高
    * 技術淘汰快：產品生命週期短，易被取代
    * 資安風險高：若軟體沒備份可能一夕倒閉

## 大學教師的條件、性質和收入
* 學歷：國內外碩博士、國內碩士+專業10年經驗
* 教學：課程多樣化，隨技術演化，常需備新課
* 授課節數：每週7-9節課
* 輔導：帶學生做專題，競賽
* 研究：撰寫研究論文報告
* 薪資：每月7萬元
* 其它收入：研究計劃、產學合作等

----

## 家庭教師的條件、性質和收入
* 以數學科為例：
    * 能力：具備口語解說能力，了解學生問題
    * 教材：幾乎不需額外時間備課
    * 學生族群：國小高年級、國中、高中
    * 上課時間：僅平日晚上、假日全天
    * 排滿時段：每週13節，每節2-3小時
    * 家教收入：每小時500-800元，每月約5-8萬
    * 上班收入：正常上下班工作薪水3-5萬
    * 累積收入：每月8-11萬，每年100-130萬
* 年輕拚10年，可累積存1000萬積蓄

## 總結與反思
* 成續越高，不代表工作一定輕鬆，收入越高
    * 但成績越高，越有條件可以選擇工作性質
* 求學黃金期國高中6年，決定未來60年的方向
    * 所以時間寶貴：Save Time vs Kill Time
* 努力不一定成功
    * 但是不努力一定不會成功
* 人生的道路要做出不斷的選擇
    * 而且選擇比努力更重要
